# FAQ

常见问题。没找到答案的话，欢迎提 [Issue](../../issues)。

## 安装相关

### Windows 下载哪个文件？
普通 64 位 Windows 用户下载 `Zynthel_<版本>_x64-setup.exe`。装完即用，不需要装 Node / Rust 等任何开发工具。

### MSI 和 EXE 有什么区别？
两者安装的是**同一个软件**，只是打包格式不同：

- `.exe`（NSIS）：双击后走标准安装向导，适合大多数个人用户；
- `.msi`：Windows Installer 格式，适合偏好 MSI 的用户或企业批量部署场景。

### 为什么 Windows 提示「未知发布者 / Windows 已保护你的电脑」？
因为当前安装包**没有商业代码签名证书**（证书需要按年付费）。这是已知的分发限制：请点击「更多信息」→「仍要运行」。安装前可以自行核对 Release 页面给出的文件信息。**不建议**为了消除这个提示去关闭 Windows Defender 或 SmartScreen。

### Android 下载哪个 APK？
下载 Release 页面提供的 APK 即可（通用包，包含 arm64 等主流架构）。安装时如系统询问「是否允许此来源安装应用」，按你的设备设置授权即可。无需 Root。

### 为什么 GitHub 上还有 Source code (zip)？
那是给开发者的**源码**，不是安装包。普通用户请从 Releases 的资产列表（Assets）里下载 `.exe` / `.msi` / `.apk`，不要下载 Source code。

### Windows ARM64 支持吗？
**Experimental（实验性）**：CI 会尝试构建 ARM64 安装包，但工具链在该平台上尚不稳定，失败时不会阻塞 x64 版本。需要稳定体验请使用 x64 版。

## 使用相关

### Zynthel 必须配置 AI 才能使用吗？
**不需要。** AI 是纯可选功能。不配置时，任务、日历、笔记、阅读、密码本、生活工具等所有本地功能都完整可用。

### 我的数据保存在哪里？
全部保存在**你的设备本地**：工作区数据在应用 WebView 的 localStorage，图片和书籍文件在 IndexedDB。项目没有服务器，也不收集任何数据。

### 可以离线使用吗？
可以。除 AI 功能外，所有功能都不需要网络。配置并使用 AI 时，请求需要联网发送给你自己配置的服务商。

### Windows 和 Android 之间能同步数据吗？
没有云同步。但可以通过「设置 → 数据」导出整包备份（ZIP），在另一台设备上导入，实现手动迁移。备份包含全部工作区数据、浮光墙图片和本地书籍。

### 忘记密码本主密码怎么办？
**无法找回。** 主密码只用于在本机派生加密密钥，项目不保存它，也没有任何重置途径（否则加密就形同虚设）。只能删除密码本数据重新开始。

### 为什么 App 要「查询所有应用」权限（QUERY_ALL_PACKAGES）？
仅用于「工具 / 快捷应用」里的 App Picker：让你从本机已安装应用中挑选一个添加为快捷入口。应用列表只在本地使用，不会收集、上传。也因为这个权限属于 Google Play 受限权限，本项目不做应用商店上架，仅 GitHub 开源 + sideload 分发。

### 卸载会丢数据吗？
会。数据存储在应用本地，卸载（或清除应用数据）后本地数据会被清除。需要保留请先在「设置 → 数据」导出整包备份。
