# Zynthel v0.1.0

Zynthel 首个公开版本。

Zynthel 是一个本地优先（local-first）的个人工作台：把任务、项目、日历、笔记、专注、阅读、密码本和 8 个生活工具收进一个界面，所有数据都保存在你自己的设备上 —— 没有账号，没有云端，没有内置密钥。

## 支持平台

- Windows x64（ARM64 为实验性构建，失败不阻塞 x64）
- Android

## 下载

### Windows

| 文件 | 说明 |
| --- | --- |
| `Zynthel_0.1.0_x64-setup.exe` | 推荐普通用户使用 |
| `Zynthel_0.1.0_x64_en-US.msi` | 同一软件的 MSI 安装包，适合偏好 MSI / 部署场景 |

> 安装包未做商业代码签名，Windows 可能提示「未知发布者」；请点「更多信息 → 仍要运行」，详见 README。

### Android

| 文件 | 说明 |
| --- | --- |
| `Zynthel_0.1.0.apk` | 通用 APK，sideload 安装 |

> 本项目不在 Google Play 上架（App Picker 需要 `QUERY_ALL_PACKAGES` 受限权限）。

## 主要功能

- 首页工作台：今日任务、即将到来的日程、最近项目、专注计时
- 任务：优先级 / 状态 / 标签 / 重复 / 截止日期
- 日历：月视图 + 中国传统节日与法定节假日徽标 + 日期格内直接添加待办
- 笔记与项目：自由记录，按项目归档，支持进度与状态
- 专注：番茄钟计时与会话记录
- 阅读：阅读清单 + 本地 PDF / EPUB 应用内阅读
- 浮光墙：本地图片墙，自由摆放、漂浮动效，图片存 IndexedDB
- 密码本：主密码 + AES-GCM/PBKDF2 本地加密
- 生活工具 8 项：记账本、健身打卡、日记、课程表、习惯打卡、倒数日、阅读清单、密码本
- 整包备份与恢复（工作区数据 + 浮光墙图片 + 本地书籍）
- 6 套内置主题；AI 纯配置入口（不内置任何服务与密钥）

## 注意事项

- Windows 安装包**未做商业代码签名**，SmartScreen 会提示「未知发布者」；
- Android 为 **GitHub 开源 + sideload** 分发，不上架 Google Play；
- AI 功能由用户自行配置接口地址、API Key 与模型，项目不内置任何 AI 服务；
- 密码本主密码遗忘**无法找回**，请妥善保管；
- 卸载会清除本地数据，需要保留请先在「设置 → 数据」导出整包备份。
